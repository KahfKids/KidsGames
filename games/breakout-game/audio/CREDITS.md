# Mosaic Breaker: sound credits

Every sound is a real recording, cut, faded and levelled by `tools/sound-cut.py` from `audio/sfx/recipe.json`.
No music, no synthesis. The old page's synthesized sounds (`js/sounds.js`) were removed on 2026-11-16.

Source of all originals: [BigSoundBank](https://bigsoundbank.com), recordings by Joseph Sardin, CC0 1.0 (licence page
checked 2026-11-16 for the four added recordings: each page says CC0, commercial use allowed, no attribution required).
"Additional sounds: Joseph SARDIN - BigSoundBank.com". The originals are kept outside the repo in
`../KidsGames-sounds/bigsoundbank/`.

| In the game | What it is for | Original (id, title) |
|-------------|----------------|----------------------|
| `break` | a tile breaks (3 takes, short, quiet) | 1643 Broken plate #1, 1645 Broken plate #3, 1648 Broken plate #6 (**downloaded for this game**, 72 / 70 / 61 KB, 2 s each) |
| `clink` | a strong or gold tile is hit but does not break yet | 1190 Small plate set on table (**downloaded for this game**, 979 KB, 25 s) |
| `bounce` | the star lands on the woven carpet (a soft cloth thump) | 0576 Canvas bag on floor |
| `tick` | the star touches a wall or the ceiling (very quiet) | 1045 Ball rebounds |
| `stone` | the star hits a carved stone tile | 0582 Four dice on wooden table |
| `launch` | the star leaves the carpet | 1797 Whoosh #5 |
| `power` | a lantern is caught (its flame flares and crackles) | 0030 Fireplace #1 |
| `lose` | the star is lost (a heart goes) | 1798 Whoosh #10 |
| `win` | the mosaic is complete (a crowd clapping) | 2363 Applause #1 |
| `star` | each star appears on the level-complete screen (a glazed piece set in place) | 0627 Cup on a table |
| `page` | a level begins | 0164 Turned page |
| `tap` | buttons | 0036 Switch desk lamp |
| `amb-0` | Desert Night: crickets, very low, looped | 1020 Field cricket |
| `amb-1` | Garden Dawn: birds waking, very low, looped | 0222 Awakening birds |
| `amb-2` | Sea Palace: waves, very low, looped | 0266 Sea waves |
