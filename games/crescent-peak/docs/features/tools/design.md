# Tools and things to wear

**Status:** designed · **Updated:** 2026-11-17 · [GDD](../../GDD.md)

In the reference, new tools open new play: a rod opens fishing, a shovel opens treasure, a bucket waters plants, a compass opens the map, shoes make you faster. Ours works the same way. Each tool is given by someone as thanks or found, never bought (pillar 3). Tools sit on a ring in the pause screen. The one in hand is picked automatically by what's near (water → rod, a dig spot → shovel), so a small child never has to switch tools.

## Tools

| Tool | From | What it opens |
|---|---|---|
| Wind shawl | Grandma, at the start | gliding; carries the [ribbons](../ribbons/design.md) |
| Bucket | the well's tap, in the village | carrying water ([quests](../quests/design.md)); watering the climbing vines, which grow into a ladder up a cliff (a shortcut) |
| Fishing rod, then the fine rod | the fisher, with the net floats help; the fine rod at 10 kinds | [fishing](../fishing/design.md) |
| Shovel | the gardener, after the bees help | digging at sparkling soft spots (shells, a lantern pattern, small finds) and the treasure maps ([side activities](../side-activities/design.md)) |
| Grandpa's map | Grandpa, after the first ribbon | a hand-drawn map on the pause screen: the landmarks and a "you are here" dot. No markers or paths on it (pillar 1) |
| Hand lantern | Grandma, at the first sunset | lights the way at night and in caves ([day and night](../day-night/design.md)) |
| Goggles | the beach children, after 5 shells | diving under the water to see the reef and collect shells |
| Rowboat oars | the fisher's son | the rowboat |
| Wooden tray | the herders on the snowy shoulder | sledding |
| Binoculars | the outlook keeper, after the lens caps help | looking far: spot hidden ribbons (they glint), dolphins and the far islet |
| Kite | the kite quest | kite flying |
| Sandals | the cobbler, after the leather help | run 15% faster on paths |

## Things to wear
Rewards from activities: a sun hat, a scarf, a woolly hat, shawl patterns, lantern patterns, the fisher's hat. They change only the look (the scarf too: the cold doesn't change stamina).
