# Recording script: Helping Home

This page is for a local imam, teacher or parent who agrees to record the phrases the game has no audio for yet. The game shows the words and waits a few seconds on each one until a recording exists. An adult male voice is preferred for the prayer words, saying them the way an imam says them in prayer: clear, calm and not sung.

## How to record

- Find a quiet room with soft things around you (a bedroom with curtains, not a bathroom or an empty hall). Turn off fans and air conditioning.
- A phone's voice memo app is fine. Hold the phone about 20 cm (a hand's length) from your mouth, a little to the side.
- Make one recording per phrase. Leave about 1 second of silence before and after you speak.
- Say each phrase once, at a calm speed. If you make a mistake, stop and record it again as a new file.
- Name each file with the file name in the tables below (any format is fine: .m4a, .mp3 or .wav).
- Please also write one line giving permission. For example: "I recorded these myself and allow Kahf to use them in the Helping Home game and to share them under CC BY 4.0." Add the name you want to be credited by (or "anonymous").

The game team then trims each file, sets the loudness, adds it to `index.json`, and credits it in `CREDITS.md`.

## 1. Arabic phrases with no audio yet

None at the moment: every phrase has a clip. Several clips come from sites that state no licence (see CREDITS.md, section C2), so re-recording them is still welcome.

When you record, please say exactly the words shown on screen (pray/prayer-text.js and pray/wudu-text.js) with no additions (for example, no "sayyidana" in the du'a after the adhan, and the salawat exactly as in Sahih al-Bukhari 3370), so the sound matches the screen. A teacher still reviews all wording.

## 3. Optional: English instructions for wudu

The wudu page speaks these with the device's built-in English voice. A calm human voice (any adult, a clear accent) would be nicer for children. Please read them slowly and warmly.
